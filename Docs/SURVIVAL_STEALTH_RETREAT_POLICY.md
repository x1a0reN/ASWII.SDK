# 生存模式突击兵隐身撤离策略

最后更新：2026-07-23

## 目标

前期躲避阶段，突击兵已经进入隐身后，不再原地等待接近者，也不再按旧的
`HiddenWatch -> HardHunt` 逻辑主动破隐。机器人优先撤离并与所有存活敌人保持
至少 20 米距离；受到伤害或隐身结束进入冷却后，才锁定为攻击模式。

## 状态规则

| 当前状态 | 事件 | 行为 |
|---|---|---|
| 前期躲避、尚未隐身 | 开局或敌人即将获得视野 | 使用隐身；等待最多 0.35 秒确认，期间禁止开火 |
| 前期躲避、正在隐身 | 敌人进入 28 米规划区并持续接近，或已经小于 23 米 | 启动隐身撤离，不攻击 |
| 隐身撤离 | 仍有存活敌人 | 目的地必须优先满足“距所有敌人 >= 23 米”，无此候选时才退到“>= 20 米” |
| 隐身撤离 | 玩家当前位置已经小于 20 米 | 选择能提升最小间距的安全候选；路径不得比当前最小间距恶化超过 0.35 米 |
| 前期躲避 | HP 或护盾实际下降 | 本局目标完成前锁定为强制攻击模式 |
| 前期躲避 | 隐身由开启变为结束，且技能进入冷却 | 本局目标完成前锁定为强制攻击模式 |
| 已完成击杀目标 | 任意 | 取消攻击锁，继续原有等待前半名次和悬崖送死流程 |

## 路径安全约束

1. 候选点按照 10、17、24 米半径和 24 个方向采样。
2. 20 米是对所有存活敌人的端点硬约束，不只检查当前接近者。
3. 23 米是首选缓冲距离，用于吸收敌人移动和重规划间隔。
4. 实际 RAIN 路径最多抽查 20 个点：
   - 玩家已经在 20 米外时，路径任何采样点都不得进入 20 米；
   - 玩家已经在 20 米内时，只允许朝间距不恶化的方向脱离；
   - 当前有掩体时，不接受会主动穿过敌人潜在视线的路线。
5. 路线仍经过 `.aswnav` 的悬崖边界、走廊净空和逐帧边缘保护，不绕开现有安全层。
6. 如果当前地形不存在任何 20 米候选点，系统不会伪造“安全”；它会选择提升
   最小间距的候选并在日志中记录 `hardSafe=False`，随后以 0.65 秒间隔继续搜索。

## 日志与验收

关键日志：

```text
SURVIVAL][ROLE stealth retreat threat=... currentMin=... destinationMin=... hardSafe=...
SURVIVAL][ROLE stealth retreat route rejected sampleMin=... floor=...
SURVIVAL][ROLE assault avoidance attack committed reason=incoming_damage
SURVIVAL][ROLE assault avoidance attack committed reason=stealth_ended_cooldown
```

构建与程序集边界审计：

```powershell
& .\Build\Build-SurvivalBotVariants.ps1 -SkipDeploy
```

该审计同时要求 Private 和 ReleaseA 均包含隐身撤离、20 米路径审计、受伤切战及
隐身结束切战方法和关键状态字符串。
