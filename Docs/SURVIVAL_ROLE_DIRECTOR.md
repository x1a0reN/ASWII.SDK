# SurvivalBot 自动职业导演与隐蔽寻路

最后更新：2026-07-23

## 1. 适用范围

该逻辑属于正式生存循环，Private 与 ReleaseA 都会编译。它没有“职业策略”“战术”“保命技能”下拉框，也不读取旧配置；运行时根据当前角色数据自动工作。

职业识别首先读取：

~~~text
Character.character_info.career
~~~

映射关系：

| CareerType | 职业 |
|---|---|
| kCareerSolider | 护卫兵 |
| kCareerGunner | 重装兵 |
| kCareerCommando | 突击兵 |

角色信息尚未同步时，使用已装备主动技能做一次后备识别；角色信息就绪后仍以 `career` 为准。

## 2. 技能依据

技能编号来自当前 `Assembly-CSharp.deobf.dll` 的 `SkillType`：

| SkillType | subtype | 用途 |
|---|---:|---|
| kSkillHeal | 0 | 护卫兵受伤治疗 |
| kSkillShield | 1 | 重装兵受伤护盾 |
| kSkillHidden | 2 | 突击兵预判隐身 |
| kSkillShockWave | 3 | 护卫兵 5m 冲击波 |
| kSkillGallop | 4 | 重装兵受伤加速 |
| kSkillArrowRain | 9 | 护卫兵 7-8m 箭雨 |

所有技能都先检查装备、`cool_down_ready` 和 `CanAction()`；动作成功后才记录为已执行。受伤后的技能响应窗口为 1.25 秒，允许护盾和加速分相邻帧发送，避免同帧两个技能互相抢占。

## 3. 职业规则

### 3.1 重装兵

- 只以 HP 实际下降作为触发，不把单纯护盾下降误判成“掉血”。
- 掉血后依次尝试护盾和加速。
- 某技能未装备或处于冷却时不伪造成功状态。

### 3.2 护卫兵

- HP 下降后立即尝试治疗。
- 任一存活敌人进入 5m 时立即尝试冲击波，包含近身隐身敌人。
- 箭雨就绪且非隐身敌人处于 6.7-8.8m、存在严格弹道视线时，锁定单一目标。
- 锁定后暂停移动，先把相机方向稳定到目标；至少经过一次视图更新后才使用箭雨。
- 短时遮挡允许 0.45 秒保持目标，避免目标在边缘抖动导致重复切换。

### 3.3 突击兵

敌人轨迹每 0.12 秒更新，保存距离收敛速度、水平速度、朝向、遮挡、隐身和无敌状态。

预判隐身条件综合：

- 当前敌人朝向玩家且即将取得无遮挡视线；
- 按敌人速度外推 0.75 秒后将取得视线；
- 10m 内无遮挡并持续接近。

预判范围上限为 22m。隐身后绑定单一导演目标：

1. 非隐身目标持续接近并进入 9m：进入 `HardHunt`，强锁直到目标失效或完成击杀。
2. 隐身目标进入 6m：立即进入 `HardHunt`。
3. 隐身目标在 6m 外继续接近：己方仍隐身时原地观察，不提前开火。
4. 隐身目标在 6m 外停止至少 0.55 秒：记录为等待状态。
5. 己方隐身先结束且对方仍在等待：进入 `RevealPursuit`，使用 RAIN 路径主动接近；进入 6m 后强锁攻击。

目标锁定期间不做分数切换，避免镜头和移动在多人之间抖动。完成条件只认 `num_killed` 增长；助攻不再提前结束击杀任务。

## 4. 击杀后与悬崖结束

- 完成一次实际击杀后停止主动职业猎杀，继续躲避并保留必要的近敌反击。
- 初始人数锁定后，仅在剩余人数不大于初始人数一半时进入结束阶段。
- 悬崖候选必须来自 RAIN 轮廓边、具备可达站立点和清晰向外起跳通道。
- 起跳通道按 5 个前向距离、3 个横向偏移共 15 个点向下探测 32m。
- 15 个点必须全部至少下降 12m；任何中心或侧向安全落脚层都会拒绝该候选。
- 多个候选优先选择最小验证落差更大的位置；全探针 32m 无地面的 void 边界优先级最高。
- 到达边缘时再次执行同一验证。跳出后若没有形成有效下降，会封禁该候选并重新选择。

物理探针只能证明“没有近距离安全落脚层”，不能静态证明服务端的具体致死阈值；因此仍保留超时后的服务端自杀兜底。

## 5. 躲避路径视线约束

安全点评分同时考虑终点遮挡和直线路径暴露。RAIN 返回实际路径后还会做第二次审计：

- 从当前点开始按约 1.8m 对剩余路径采样，最多检查 14 个样本；
- 对每个样本检查 42m 内相关敌人的身体视线；
- 当前处于掩体内而路径将穿过敌方视线时，拒绝该安全点并重新寻路；
- 当前已经暴露时不阻断逃离路径，避免为了寻找完美路线卡在原地。

最近已消失的隐身敌人只在 1.25 秒内参与远距离路线视线评分；6m 内仍按近敌威胁处理，减少不自然地响应长期不可见目标。

## 6. 关键日志

~~~text
[SURVIVAL][ROLE] detected=...
[SURVIVAL][ROLE] damage response sequence=...
[SURVIVAL][ROLE] assault state ...
[SURVIVAL][ROLE] director=hidden_watch|reveal_pursuit|hard_hunt ...
[SURVIVAL] hide route rejected sightSamples=...
[SURVIVAL] reachable cliff candidate ... verifiedMinDrop=...
~~~

双版本构建脚本使用 Mono.Cecil 强制检查上述导演、技能适配、路线审计和悬崖验证方法都存在，任一版本缺失都会停止打包和部署。
